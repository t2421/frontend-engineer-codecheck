# Preview性能の見方

PRの画面を、PCとスマホに相当する条件の自動ブラウザーで、それぞれ3回読み込みます。
Lighthouseという性能検査ツールで次の3項目を測り、項目ごとに3回の真ん中の値（中央値）で評価します。
性能の計測にはLighthouseを使い、操作・表示・アクセシビリティ（使いやすさ）の確認にはPlaywrightを使います。

- **LCP（表示速度）**: 画面の主な内容が表示されるまでの時間。
- **CLS（表示のずれ）**: 読み込み中に文字やボタンなどの位置がずれる程度。
- **TBT（処理の重さ）**: 読み込み中の重い処理で、操作に応答しにくくなる時間。

値が小さいほど良好です。🟢 良好／🟡 改善が必要／🔴 不良を項目ごとに表示し、最も厳しい判定を総合とします。
測定に失敗した場合や3回分の値がそろわない場合は⚪ 判定不可です。性能判定は参考表示で、変更の取り込みを自動で止めません。

自動ブラウザーによる参考測定であり、実際の利用者の操作を測ったものではなく、操作時の反応や実データ取得の待ち時間を含む最終評価は #36 で確認します。

詳しい条件と判定基準は[計測・判定のコード](../.github/scripts/review-performance.mjs)、測定時の情報やエラーは[Actionsの実行結果](https://github.com/t2421/frontend-engineer-codecheck/actions/workflows/review-publish.yml)で確認できます。
