# 都道府県別人口推移アプリ仕様

## 目的

都道府県ごとの人口の増減を可視化し、地域間や人口区分ごとの変化を比較できるようにする。

## 受入条件

課題指定の都道府県・人口データに基づき、次を満たす。

| 実現できること                           | 観測可能な受入条件                                                                                                                                                                          |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 全国の都道府県を選んで比較する           | 指定APIから取得した都道府県情報をもとに、各都道府県のチェックボックスを動的に表示する。47都道府県を選択でき、2県以上を選択すると各県の線が表示され、1県を解除するとその県の線だけが消える。 |
| 人口の推移を読み取る                     | 選択した県の人口が、横軸「年」・縦軸「人口数」の折れ線で表示される。県と線の対応が分かり、表示値が元データと一致する。                                                                      |
| 人口区分を切り替える                     | 総人口・年少人口・生産年齢人口・老年人口を切り替えると、表示中の区分が分かり、線がその区分の値に変わる。選択した県のチェック状態と表示対象は維持される。同時表示は求めない。                |
| PC・タブレット・スマートフォンで利用する | Google Chrome最新版の各画面幅で、都道府県の選択・解除、区分の切替、グラフの閲覧ができ、文字や操作部品が重なって使えなくならない。                                                           |
| 未選択状態から利用を始める               | 初期表示は都道府県未選択・人口区分は総人口。グラフ領域に「都道府県を選択すると、人口の推移を確認できます」と表示する。選択した県をすべて解除した場合も同じ案内を表示する。                  |
| 読み込み中・取得失敗が分かる             | 初回を含むデータ取得中なら読み込み表示、取得失敗なら失敗を知らせる表示が出る。                                                                                                              |
| 取得失敗から再試行する                   | 失敗時に再試行を操作でき、取得に成功すると対象の一覧またはグラフが表示される。                                                                                                              |

## 課題の制約と提出

[課題の正本](https://github.com/yumemi-inc/frontend-engineer-codecheck/blob/main/README.md)と[指定API仕様](https://github.com/yumemi-inc/frontend-engineer-codecheck/blob/main/docs/api.md)を参照します。VueとTypeScriptでSPAを実装し、指定API・サードパーティ製グラフ・自前CSSを使用します。Chrome最新版でPC・スマートフォンに対応し、lint・format・テストを設定してセキュリティを考慮します。

提出にはGitHubのpublicリポジトリURL、インターネットで閲覧できるデプロイURL、合計作業時間、総合的なプログラミング歴、Webフロントエンド歴が必要です。参考資料とAI利用成果の簡潔なレポートは任意です。作業時間・経歴は本人が記入し、未確認の完了や実績を記載しません。
